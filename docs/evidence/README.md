# Evidence directory

Store real screenshots, command outputs, performance measurements, and demo evidence here as they are generated. No application evidence exists at planning time.

Suggested names: `YYYYMMDD-HHMM-card-check.txt`, `YYYYMMDD-HHMM-dashboard-desktop.png`, `YYYYMMDD-HHMM-performance.json`.

Each item should identify the commit, actual IST timestamp, actor/role, method, result, and limitations. Exclude credentials, session cookies, real email content, local databases, or unrelated personal data. Local demo-only data is sufficient.
